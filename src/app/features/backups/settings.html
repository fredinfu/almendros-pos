Instalar en iPad

  1. Abre la dirección HTTPS de la aplicación en Safari.
  2. Usa Compartir → Agregar a pantalla de inicio.
  3. Abre el icono, espera a que se prepare y revisa el almacenamiento.
  4. Prueba el modo avión antes de llevarla al evento.

La versión de desarrollo por IP local permite revisar la interfaz, pero requiere HTTPS para habilitar la PWA.
